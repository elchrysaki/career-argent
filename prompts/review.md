# ARGENT human/source review checklist

For one local opportunity under `.local/opportunities.json`:
1. Open the official application and verify this cycle's date (not last year's).
2. Check citizenship, residence, current institution, bachelor/master status, study year and graduation date.
3. Check actual funding breakdown: tuition/fee waiver, stipend, food, housing, flights, local travel, visas, insurance.
4. Record exact source URLs and the date you checked them.
5. Verify linked public faculty/contact profiles and program-specific outreach policy.
6. If all essential fields are actually corroborated, change the LOCAL record verification to `official`; otherwise leave `review`.
7. If explicitly ineligible, mark `ineligible` but preserve the listing for potential future planning.
8. Never edit or commit a file outside `.local/` with an individual's interests, decisions or application details.
