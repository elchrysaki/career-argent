02 / Start privately

Your research, your machine.

The public site is a project introduction, not a cloud copy of the personal dashboard. Clone the software, set your preferences on your own computer, and optionally connect your authenticated AI agent.

git clone https://github.com/elchrysaki/career-argent.git
cd career-argent
npm run setup
npm start

Then open http://127.0.0.1:4178 to configure local preferences, choose funding requirements and track applications.

Full setup guide ↗Download starter

Node.js 20+ required. Daily research requires an authenticated Claude Code or Codex CLI with live research access. The local computer must be on for scheduled runs. External model providers receive research prompts under their own terms.
